# 대표 화면 점검 2차 (3단계)

- 날짜: 2026-10-26
- 대상: 기존 컴포넌트만으로 조립한 대표 화면 세 개
  - 3번 대화 기록 (`examples/chat-history.tsx`, Storybook `조합/대화 기록`): Sidebar, 검색, 이름 바꾸기·삭제 메뉴, 이름 바꾸기 대화상자, 삭제 확인, 실행 취소 토스트
  - 4번 기억·설정 (`examples/memory-settings.tsx`, `조합/기억·설정`): AI 기억 보기·고치기·지우기, 배경 올리기와 흐림·불투명도 조절, 오류 메시지가 있는 입력 폼
  - 6번 게임 상세 (`examples/game-detail.tsx`, `조합/게임 상세`): 이동 경로, 아이콘·통계, 스크린샷, 게임 정보 펼치기, 좋아요 비율 평가, 댓글
- 확인 조건: 1280px·375px 폭, 라이트·다크, 기본·로딩·빈 상태·오류·긴 한국어, 키보드 Tab·Escape, 포커스 이동과 복귀, axe(`@axe-core/playwright`), 접근성 트리(`ariaSnapshot`)
- 화면 3, 4는 사용자의 개인 AI 프로젝트 "하늘" 기준입니다. 고치기는 4단계, 새 컴포넌트는 5·6단계에서 합니다. 이 문서는 문제 목록입니다.
- [1차 점검](./GAME-DISCOVERY-AUDIT.md)과 같은 문제는 아래 "1차와 겹치는 문제"에 번호만 적었습니다. 이 문서의 번호는 1차와 구분하려고 `2-`를 붙입니다.

> **3.5단계 정정(2026-10-26):** 처음 조합은 빈 곳을 화면 CSS(`examples/*.css`)로 채웠는데, 그 CSS 상당수가 라이브러리 배치 컴포넌트·토큰을 쓰지 않은 조합 결함이었습니다. 세 화면을 다시 짰고(화면 CSS는 라이브러리 클래스를 덮지 않고 토큰만 쓰는 배치용으로만 남깁니다), 원인이 조합이었던 항목은 "정정"으로 표시했습니다. 자세한 내용은 [조합 화면 검토](./COMPOSITION-REVIEW.md)를 봅니다. 필요한 아이콘이 없어 예제에서는 lucide 아이콘을 썼습니다(1차 M10).

## 심각도 기준

1차와 같습니다.

- **높음:** 기본값으로 쓰면 깨지거나, 보조기기·키보드 사용자가 작업을 끝내기 어렵거나, 문서와 동작이 다릅니다.
- **중간:** 화면은 만들 수 있지만 우회 코드가 필요하거나, 의미 구조·발견성이 부족합니다.
- **낮음:** 다듬을 부분입니다.

## 1차와 겹치는 문제

이번 화면에서도 다시 확인했습니다. 내용은 1차 문서를 봅니다.

- 1차 H1 글꼴 대체: 기억 목록과 폼 라벨의 영문·숫자("React와 TypeScript", "10월 24일", 좋아요 수)가 명조로 표시됨.
- 1차 H3 Carousel 영역 이름 중복: 게임 상세 스크린샷.
- 1차 H4 줄바꿈: Alert 제목 "못했/습니다", 기억 문장 "산/책", 댓글 본문.
- 1차 H5 Alert: 세 화면의 오류 상태 모두 일반 안내와 같은 모양.
- 1차 M7 Typography: 페이지 제목에 `h1`이 필요합니다. 처음 게임 상세는 `h1`에 글자 크기를 직접 지정했는데(조합 결함), 지금은 모든 화면이 `Heading`(h2)을 써서 `h1`이 없습니다.
- 1차 M9 로딩 안내, M10 아이콘(연필, 휴지통, 엄지, 하트, 공유, 업로드, 사이드바), L1 Empty 구성.

## 잘 된 점

- 375px에서 가로 스크롤이 생기지 않았습니다(모든 상태에서 `scrollWidth` = 화면 폭).
- Form 검증: 빈 값 제출 시 첫 오류 입력으로 포커스가 가고 `aria-invalid`·`aria-describedby`가 연결됩니다. 서버 오류(`Form errors`)는 입력을 고치면 사라집니다.
- Menu는 `menu`/`menuitem` 역할과 트리거 이름("… 더보기")이 맞습니다. 대화상자를 Escape로 닫으면 여는 버튼으로 돌아옵니다.
- AlertDialog는 첫 포커스가 "취소"라 실수로 삭제하지 않습니다.
- 모바일 Sidebar는 대화상자로 바뀌어 포커스가 안에 갇히고, 제목과 닫기 버튼이 있습니다.
- Toast의 "실행 취소"로 지운 대화를 원래 자리에 되돌릴 수 있습니다.

## 확인하지 못한 것

- 실제 스크린 리더(VoiceOver, NVDA, TalkBack) 읽기, Safari·iOS·Android 실기기, 200% 확대, RTL, 고대비 모드.
- 실제 파일 올리기(이미지·GIF·MP4)와 터치 드래그 슬라이더.
- Roblox CDN 글꼴이 정상으로 불러와진 상태(이 환경에서는 CDN 접속이 막혀 있었습니다).
