# 게임 탐색 화면 점검 (2단계 점검 1차)

- 날짜: 2026-10-26
- 대상: 기존 컴포넌트만으로 조립한 게임 탐색 화면 (`examples/game-discovery.tsx`, Storybook `조합/게임 탐색`)
- 구성: 검색, 히어로 배너, 장르 필터, 인기 게임 가로 목록, 실시간 차트
- 확인 조건: 1280px·375px 폭, 라이트·다크, 기본·로딩·빈 상태·오류·긴 한국어, 키보드 Tab·방향키, axe(`@axe-core/playwright`), 접근성 트리(`ariaSnapshot`)
- 고치기는 4단계, 새 컴포넌트는 5·6단계에서 합니다. 이 문서는 문제 목록입니다.

조립하면서 컴포넌트가 해결하지 못해 화면 CSS(`examples/game-discovery.css`)로 채운 곳은 모두 아래 목록에 들어 있습니다.

## 설계 메모

홈 화면은 대시보드가 아닙니다. 처음 조립에서는 실시간 차트를 테두리 상자 안의 행 목록에 순위 변화 배지(▲·▼)까지 넣어 대시보드처럼 만들었는데, 사용자 지적(2026-10-26, 구글 플레이 참고)에 따라 **구분선과 상자가 없는 일반 목록이 넓은 화면에서 세 줄씩 옆 열로 이어지는 형태**로 바꿨습니다. 차트 종류는 목록 위의 선택 그룹으로 바꿉니다. 항목은 순위, 썸네일, 제목, 장르, 좋아요 비율만 보여 주고 상세 화면 링크입니다. 순위 항목 컴포넌트(6단계)도 이 형태를 기준으로 합니다.

## 심각도 기준

- **높음:** 기본값으로 쓰면 깨지거나, 보조기기·키보드 사용자가 작업을 끝내기 어렵거나, 문서와 동작이 다릅니다.
- **중간:** 화면은 만들 수 있지만 우회 코드가 필요하거나, 의미 구조·발견성이 부족합니다.
- **낮음:** 다듬을 부분입니다.

## 잘 된 점

- 라이트·다크 모두 axe 색 대비 위반이 없었습니다(이미지 위 글자는 axe가 계산하지 못하므로 미검증).
- 375px에서 가로 스크롤이 생기지 않았습니다(모든 상태에서 `scrollWidth` = 화면 폭).
- ToggleGroup 방향키 이동과 Space 선택, Carousel 끝에서 비활성 버튼의 포커스 유지가 동작합니다.
- 모션 감소 설정에서 Skeleton 애니메이션이 꺼집니다(`theme.css` 공통 규칙).

## 확인하지 못한 것
