## 구성

55개 컴포넌트와 공통 디자인 토큰을 제공합니다. 컴포넌트 파일을 프로젝트에 복사한 뒤 수정해서 사용합니다.

- [설치](/docs/installation): 의존성, 스타일, import 경로 설정
- [컴포넌트](/docs/components): 사용법과 실행 예제
- [디자인 토큰](/docs/foundations): 색상, 간격, 크기 값
- [조합 예제](/docs/patterns): 설정 화면과 대화상자

## 예제 사용

예제의 **코드** 탭에서 실행 중인 코드를 확인하고 복사합니다. **새 창**에서는 예제를 전체 화면으로 확인할 수 있습니다. 예제의 라이트·다크 테마는 문서 테마와 별도로 전환합니다.

예제의 입력과 저장 결과는 페이지를 새로고침하면 초기화됩니다. 서버 저장, 인증 코드 검증, 메시지 전송은 연결되어 있지 않습니다.

## 출처

Roblox의 공개 CSS와 화면을 참고한 독립 구현입니다. Roblox 공식 패키지가 아니며, 내부 디자인 시스템 전체를 포함하지 않습니다. [출처와 범위](/docs/sources)를 확인하세요.
