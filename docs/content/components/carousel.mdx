## 설치

```sh
pnpm ui add carousel icon --cwd ../my-app
```

[공통 설치 설정](/docs/installation)을 먼저 적용합니다.

## 사용법

`items`의 고유 ID, 제목, 설명, 미디어를 가로 목록으로 표시합니다. `onItemClick`은 선택한 ID를 전달합니다. 앞뒤 이동 버튼과 직접 스크롤을 사용할 수 있습니다.
