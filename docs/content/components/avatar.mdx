## 설치

```sh
pnpm dlx ply-ui add avatar
```

[공통 설치 설정](/docs/installation)을 먼저 적용합니다.

## 사용법

사용자 이미지가 있으면 `Image`에 `src`와 `alt`를 지정합니다. 이미지가 없거나 로딩에 실패하면 `Fallback`이 표시됩니다.

## 구성

| 구성 요소  | 역할                                                  |
| ---------- | ----------------------------------------------------- |
| `Root`     | 이미지와 대체 표시를 묶습니다.                        |
| `Image`    | 사용자 이미지입니다. `src`와 `alt`를 지정합니다.      |
| `Fallback` | 이미지가 없거나 불러오지 못했을 때 표시할 내용입니다. |

## 대체 표시

이미지가 없거나 불러오지 못하면 `Fallback` 내용을 표시합니다.
