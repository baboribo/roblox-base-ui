## 설치

```sh
pnpm dlx ply-ui add input field icon
```

[공통 설치 설정](/docs/installation)을 먼저 적용합니다.

## 사용법

입력 이름은 `label` 또는 `Field.Label`로 연결합니다. `variant`는 표면, `controlSize`는 높이입니다. 기본값은 `standard`와 `lg`입니다.

## Standard

`variant="standard"` — 투명한 배경과 테두리를 사용합니다. 기본값입니다.

<ComponentExample name="input-standard" title="Standard" />

## Contrast

`variant="contrast"` — 배경 대비를 높인 입력 영역입니다.

<ComponentExample name="input-contrast" title="Contrast" />

## Utility

`variant="utility"` — 배경과 테두리가 없는 입력 영역입니다.

<ComponentExample name="input-utility" title="Utility" />

## 크기

`controlSize`로 높이를 지정합니다. 기본값은 `lg`입니다. HTML의 `size`는 글자 수에 따른 너비이므로 구분해서 사용합니다.

<ComponentExample name="input-sizes" title="크기" />

## 비활성

`disabled`는 입력과 포커스 이동을 막습니다.

<ComponentExample name="input-disabled" title="비활성" />

## 읽기 전용

`readOnly`는 값을 수정하지 못하게 합니다. 값 선택과 복사는 가능합니다.

## 오류

`Field.Root`의 `invalid`로 오류 상태를 지정합니다. 같은 Root 안의 Input과 `Field.Error`는 오류 상태와 설명을 공유합니다.

<ComponentExample name="input-invalid" title="오류" />

## 장식과 너비 지정

`leading`·`trailing` 유무와 관계없이 `className`과 `style`은 전체 입력 표면에 적용합니다. `ref`, 이벤트와 입력 속성은 실제 `input`에 연결합니다. 내부 글자나 입력 자체만 꾸밀 때는 `inputClassName`·`inputStyle`을 사용합니다.

```tsx
<Input leading={<Icon name="icon-regular-person" />} className="max-w-64" />
```
