## 설치

```sh
pnpm dlx ply-ui add menubar menu
```

[공통 설치 설정](/docs/installation)을 먼저 적용합니다.

## 사용법

여러 Menu를 가로로 묶는 상위 영역입니다. 각 Menu는 독립적인 Trigger와 Popup을 가지며, Menubar는 메뉴 사이의 키보드 이동을 담당합니다.
