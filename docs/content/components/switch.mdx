## 설치

```sh
pnpm dlx ply-ui add switch
```

[공통 설치 설정](/docs/installation)을 먼저 적용합니다.

## 사용법

하나의 설정을 켜거나 끌 때 사용합니다. `Root`와 `Thumb`을 조합하고 label로 설정 이름을 연결합니다.

## 구성

| 구성 요소 | 역할                                                                            |
| --------- | ------------------------------------------------------------------------------- |
| `Root`    | 켜짐 상태와 크기를 관리합니다. `checked`와 `onCheckedChange`로 제어합니다.      |
| `Thumb`   | 현재 상태에 따라 움직이는 손잡이입니다. 체크 아이콘은 내부에 포함되어 있습니다. |

## 크기

`size`의 기본값은 `md`입니다. 너비 × 높이는 `xs` 28×16, `sm` 32×20, `md` 40×24, `lg` 44×24px입니다.
