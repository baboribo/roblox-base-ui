## 설치

```sh
pnpm ui add checkbox icon --cwd ../my-app
```

[공통 설치 설정](/docs/installation)을 먼저 적용합니다.

## 사용법

각 항목을 독립적으로 선택할 때 사용합니다. `Root`를 label로 감싸고 선택 표시를 `Indicator`에 넣습니다. 여러 항목의 값을 함께 관리하려면 [Checkbox Group](/docs/components/checkbox-group)을 사용합니다.

## 구성

| 구성 요소   | 역할                                                                                                         |
| ----------- | ------------------------------------------------------------------------------------------------------------ |
| `Root`      | 체크 영역과 선택 상태입니다. `checked`, `onCheckedChange`, `indeterminate`, `disabled`, `size`를 지정합니다. |
| `Indicator` | 선택 또는 일부 선택 상태의 표시를 담습니다.                                                                  |

## 선택된 초기값

`defaultChecked`로 초기 선택 상태를 지정합니다. 이후에는 사용자가 선택을 바꿀 수 있습니다.

<ComponentExample name="checkbox-checked" title="선택된 초기값" />

## 비활성

`disabled`를 지정하면 선택 상태를 바꿀 수 없습니다.

<ComponentExample name="checkbox-disabled" title="비활성" />

## 일부 선택

`indeterminate`로 하위 항목 중 일부가 선택된 상태를 표시합니다. 하위 항목과의 상태 계산은 별도로 연결합니다.

<ComponentExample name="checkbox-indeterminate" title="일부 선택" />

## 크기

`size`의 기본값은 `sm`입니다. 현재 `md`와 `lg`는 모두 24px로 표시됩니다.
