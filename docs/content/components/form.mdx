## 설치

```sh
pnpm dlx ply-ui add form button field
```

[공통 설치 설정](/docs/installation)을 먼저 적용합니다.

## 사용법

여러 Field의 검증과 제출을 묶습니다. `onSubmit`에서 기본 제출을 막고 FormData를 읽을 수 있습니다. 예제는 이메일 검증 후 로컬 완료 상태를 표시합니다.
