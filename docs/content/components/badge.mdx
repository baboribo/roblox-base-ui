## 설치

```sh
pnpm ui add badge --cwd ../my-app
```

[공통 설치 설정](/docs/installation)을 먼저 적용합니다.

## 사용법

짧은 상태나 개수를 표시합니다. Badge는 span 요소이며 클릭 동작이나 선택 상태를 관리하지 않습니다.

## Standard

`variant="standard"` — 기본 중립 색상입니다.

<ComponentExample name="badge-standard" title="Standard" />

## Contrast

`variant="contrast"` — 명암 대비가 큰 배경입니다.

## 크기

`size`는 `xs`와 `sm`입니다. 기본값은 `sm`입니다.
