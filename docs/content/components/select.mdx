## 설치

```sh
pnpm ui add select --cwd ../my-app
```

[공통 설치 설정](/docs/installation)을 먼저 적용합니다.

## 사용법

목록의 값 하나를 선택할 때 사용합니다. `Root.items`와 `Item.value`를 맞추면 `Value`가 선택한 레이블을 표시합니다. 작업 실행 목록은 [Menu](/docs/components/menu)를 사용합니다.

## 구성

| 구성 요소                         | 역할                                                                                  |
| --------------------------------- | ------------------------------------------------------------------------------------- |
| `Root`                            | 항목 데이터와 선택 상태를 관리합니다. `items`, `value`, `onValueChange`를 지정합니다. |
| `Trigger`                         | 현재 값이 표시되는 버튼입니다. `size`는 이 버튼의 높이입니다.                         |
| `Value`                           | 선택한 항목의 레이블을 표시합니다. 선택 전에는 `placeholder`를 표시합니다.            |
| `Icon`                            | 펼침 표시를 담습니다.                                                                 |
| `Portal`                          | 목록을 문서의 별도 영역에 렌더합니다.                                                 |
| `Positioner`                      | 목록의 위치를 정합니다. 기본 `sideOffset`은 8, `alignItemWithTrigger`는 false입니다.  |
| `Popup`                           | 목록의 표면입니다. `size`는 내부 항목의 글자와 여백입니다.                            |
| `List`                            | 선택 항목을 담습니다.                                                                 |
| `Item`                            | `value`로 항목을 식별합니다. 항목마다 다른 값을 지정합니다.                           |
| `ItemText`                        | 항목의 레이블입니다.                                                                  |
| `ItemIndicator`                   | 선택된 항목에 표시할 체크 표시입니다.                                                 |
| `Group / GroupLabel`              | 항목을 묶고 그룹 이름을 표시합니다.                                                   |
| `Separator`                       | 항목 사이 구분선입니다.                                                               |
| `ScrollUpArrow / ScrollDownArrow` | 목록을 위아래로 스크롤할 수 있을 때 표시합니다.                                       |

## 선택값 제어

`Root.value`와 `onValueChange`로 선택값을 관리합니다. `items`의 레이블이 닫힌 버튼에도 표시됩니다.

<ComponentExample name="select-controlled" title="선택값 제어" />

## 버튼과 목록 크기 분리

Trigger의 크기는 닫힌 버튼에, Popup의 크기는 열린 목록에 적용됩니다. 이 예제는 `Trigger size="sm"`과 `Popup size="lg"`를 조합합니다.

<ComponentExample name="select-mixed-sizes" title="버튼과 목록 크기 분리" />

## 여러 값 선택
