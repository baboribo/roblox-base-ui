## 설치

```sh
pnpm dlx ply-ui add pagination
```

## 사용법

`pageCount`는 전체 페이지 수이며, `page`는 1부터 시작합니다. `onPageChange`에서 표시할 데이터와 현재 페이지를 갱신합니다. 페이지가 많으면 처음·끝·현재 주변 페이지를 남기고 중간을 생략합니다.

이 컴포넌트는 페이지 선택 UI입니다. 서버 요청과 URL 변경은 사용하는 앱에서 처리합니다. 필터가 바뀌어 페이지 수가 줄면 앱의 현재 페이지도 함께 조정하세요. 범위를 벗어난 `page`는 표시 가능한 범위로 제한하고, 페이지가 0개면 탐색 UI를 숨깁니다.

## 내부에서 페이지 관리

`page` 없이 `defaultPage`를 지정하면 선택 상태를 내부에서 관리합니다.

## 비활성

요청 중 중복 이동을 막으려면 `disabled`를 지정합니다. 처음과 마지막 페이지에서는 해당 방향의 이동 버튼만 자동으로 비활성화됩니다.

<ComponentExample name="pagination-disabled" title="비활성" />

## 접근성

현재 페이지에는 `aria-current="page"`를 지정합니다. Tab으로 버튼을 이동하고 Enter 또는 Space로 선택합니다. 페이지 이동 영역이 여러 개라면 각각 다른 `aria-label`을 지정합니다. `getPageLabel`로 번호 버튼의 읽기 이름을 바꿀 수 있습니다.
