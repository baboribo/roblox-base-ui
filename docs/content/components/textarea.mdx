## 설치

```sh
pnpm dlx ply-ui add textarea
```

[공통 설치 설정](/docs/installation)을 먼저 적용합니다.

## 사용법

여러 줄의 텍스트를 입력합니다. label로 이름을 연결하고 `rows`로 표시할 줄 수를 지정합니다. 별도의 size나 variant 속성은 제공하지 않습니다.

## 비활성

`disabled`로 입력을 막습니다. 읽기와 복사는 허용하려면 `readOnly`를 사용합니다.
