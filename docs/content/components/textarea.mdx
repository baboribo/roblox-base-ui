## 설치

```sh
pnpm dlx ply-ui add textarea
```

[공통 설치 설정](/docs/installation)을 먼저 적용합니다.

## 사용법

여러 줄의 텍스트를 입력합니다. label로 이름을 연결하고 `rows`로 표시할 줄 수를 지정합니다. `controlSize`로 글자 크기를, `variant`로 배경과 테두리를 지정합니다. Input과 같은 값을 사용합니다.

## 비활성

`disabled`로 입력을 막습니다. 읽기와 복사는 허용하려면 `readOnly`를 사용합니다.

<ComponentExample name="textarea-disabled" title="비활성" />

## 크기와 오류 상태

`rows`로 줄 수를 지정합니다. `aria-invalid="true"`는 오류 테두리를 표시하며, `aria-describedby`로 오류 설명을 연결합니다. 기본 최소 높이는 100px입니다.
