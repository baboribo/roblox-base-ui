## 설치

```sh
pnpm dlx ply-ui add alert
```

[공통 설치 설정](/docs/installation)을 먼저 적용합니다.

## 사용법

AlertTitle과 AlertDescription으로 제목과 설명을 구분합니다.

화면에 유지되는 안내에 사용합니다. 일시적인 작업 결과는 Toast를 사용합니다.

## 종류

`tone`으로 안내의 종류를 고릅니다. 종류는 테두리와 옅은 바탕색으로 구분하고, 글자색은 대비를 지키기 위해 바꾸지 않습니다. 색을 구분하기 어려운 사용자도 알 수 있도록 제목에 상황을 적습니다.

<ComponentExample name="alert-tones" title="종류" />

| `tone`             | 쓰는 곳                   | 기본 `role` |
| ------------------ | ------------------------- | ----------- |
| `neutral` (기본값) | 일반 안내                 | `status`    |
| `success`          | 끝난 작업의 결과          | `status`    |
| `warning`          | 곧 문제가 될 수 있는 상태 | `status`    |
| `error`            | 작업을 막는 오류          | `alert`     |

`role="alert"`는 보조기기가 하던 말을 멈추고 바로 읽으므로 사용자가 바로 알아야 하는 오류에만 씁니다. 처음부터 화면에 있는 안내라면 `role`을 직접 지정해 바꿀 수 있습니다.

## 제목 수준

`AlertTitle`은 기본 `h3`입니다. 페이지 제목 바로 아래에 두면 `as="h2"`, 제목 계층에 넣지 않을 때는 `as="p"`를 씁니다.

## 구성

| 구성 요소          | 역할                                                                                  |
| ------------------ | ------------------------------------------------------------------------------------- |
| `Alert`            | 알림 내용을 묶습니다. 기본 `role`은 `tone="error"`일 때 alert, 나머지는 status입니다. |
| `AlertTitle`       | 알림 제목입니다. `as`로 제목 수준을 고릅니다.                                         |
| `AlertDescription` | 알림의 상세 내용입니다.                                                               |
