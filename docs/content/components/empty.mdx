## 설치

```sh
pnpm ui add empty button --cwd ../my-app
```

[공통 설치 설정](/docs/installation)을 먼저 적용합니다.

## 사용법

표시할 데이터가 없을 때 제목, 설명, 작업 버튼을 배치하는 section입니다. 자체 상태나 데이터 조회 기능은 없습니다.
