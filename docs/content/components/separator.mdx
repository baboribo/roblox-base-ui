## 설치

```sh
pnpm dlx ply-ui add separator
```

[공통 설치 설정](/docs/installation)을 먼저 적용합니다.

## 사용법

내용 사이를 구분합니다. 기본 방향은 가로이며 `orientation="vertical"`로 세로 구분선을 표시합니다.

## 세로 방향

세로 구분선은 높이가 있는 flex 영역 안에 배치합니다.
