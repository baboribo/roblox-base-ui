## 모션

97.5% 크기에서 300ms 동안 부드럽게 나타나고, 200ms 동안 작아지며 사라집니다. 중심 위치는 유지합니다. 움직임 감소 설정에서는 전환을 생략합니다. [공통 모션 규칙](/docs/motion)을 따릅니다.

## 설치

```sh
pnpm dlx ply-ui add dialog button input
```

[공통 설치 설정](/docs/installation)을 먼저 적용합니다.

## 사용법

현재 화면 위에서 입력하거나 작업할 때 사용합니다. `Title`로 목적을 설명하고 `open`과 `onOpenChange`로 열림을 제어합니다. 예제의 저장 동작은 로컬 상태만 변경합니다.

## 구성

| 구성 요소         | 역할                                                                  |
| ----------------- | --------------------------------------------------------------------- |
| `Root`            | 열림 상태를 관리합니다. `open`과 `onOpenChange`로 제어할 수 있습니다. |
| `Trigger`         | 대화상자를 여는 버튼입니다.                                           |
| `Portal`          | 대화상자와 배경을 별도 영역에 렌더합니다.                             |
| `Backdrop`        | 뒤 화면을 덮는 배경입니다.                                            |
| `Popup`           | 내용과 포커스를 담습니다. `size`로 너비를 지정합니다.                 |
| `Title`           | 대화상자의 접근 가능한 이름입니다.                                    |
| `Description`     | 대화상자의 목적이나 입력 안내입니다.                                  |
| `Body`            | 본문 여백을 구성합니다. Popup의 직접 자식으로 둡니다.                 |
| `Footer`          | 하단 작업 버튼의 여백과 정렬을 구성합니다.                            |
| `Close`           | 닫기 동작을 연결한 버튼입니다.                                        |
| `CloseAffordance` | Popup 오른쪽 위의 닫기 아이콘 버튼입니다.                             |

## 크기 SM

`Popup size="sm"`의 최대 너비는 320px입니다. 화면이 좁으면 화면 너비에 맞게 줄어듭니다.
