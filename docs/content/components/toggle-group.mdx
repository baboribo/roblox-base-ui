## 설치

```sh
pnpm ui add toggle-group toggle --cwd ../my-app
```

[공통 설치 설정](/docs/installation)을 먼저 적용합니다.

## 사용법

Toggle 여러 개의 선택값을 배열로 관리합니다. `multiple`을 지정하면 여러 항목을 동시에 선택합니다. 각 Toggle에는 고유한 `value`를 지정합니다.

## 하나만 선택

`multiple`을 생략하면 하나의 값만 선택합니다. 값은 단일 선택에서도 배열로 관리합니다.
