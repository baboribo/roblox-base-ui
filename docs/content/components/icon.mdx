## 설치

```sh
pnpm ui add icon --cwd ../my-app
```

[공통 설치 설정](/docs/installation)을 먼저 적용합니다.

## 사용법

`name`으로 아이콘을 고릅니다. `size`는 픽셀 단위이며 기본값은 20입니다. 색상은 부모의 `color`를 따릅니다. 기본적으로 장식 요소이므로 버튼 이름은 버튼의 `aria-label`로 지정합니다.
