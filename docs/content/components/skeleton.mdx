## 설치

```sh
pnpm ui add skeleton --cwd ../my-app
```

[공통 설치 설정](/docs/installation)을 먼저 적용합니다.

## 사용법

내용을 불러오는 동안 사용할 자리 표시입니다. `style`로 너비와 높이를 지정합니다. 기본적으로 스크린 리더에서 숨겨지므로 로딩 안내는 별도로 제공합니다.
